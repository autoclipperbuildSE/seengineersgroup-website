# Auto Clipper Website v2

Official product website for Auto Clipper, developed by SE Engineers Group.

## Deploy to Vercel

1. Replace the existing website files in the GitHub repository with this package.
2. Commit and push to the production branch.
3. Confirm the new Vercel production deployment.
4. Verify these URLs return HTTP 200:
   - `/`
   - `/privacy`
   - `/terms`
   - `/contact`
   - `/assets/favicon.ico`
5. Use `assets/icon-1024.png` as the TikTok app icon so the website, browser tab and TikTok app use the same mark.

## Before publishing

Confirm that `support@seengineersgroup.com` is a working inbox. Replace it in the HTML files if another support address should be used.
